# Gesture Translator Glove using Flex Sensors

## Overview

The LESS sign glove is a wearable assistive technology project designed to help bridge communication gaps for deaf and speech-impaired individuals. The system uses flex sensors attached to a glove to detect finger movements and hand gestures. These gestures are processed by a microcontroller and translated into predefined words, phrases, or speech outputs.

Unlike camera-based gesture recognition systems, this project is lightweight, portable, affordable, and works without external cameras or heavy image processing.

The project also includes a mobile application where users can customize and save gestures with corresponding words or phrases for personalized communication.

# Working Principle

1. Flex sensors attached to the glove detect finger bending.
2. Sensor values are sent to the microcontroller.
3. The microcontroller compares the readings with stored gesture patterns.
4. The matched gesture is translated into text or speech.
5. The connected mobile application displays or speaks the output.
6. Users can customize gestures and save their own words or phrases through the app.
